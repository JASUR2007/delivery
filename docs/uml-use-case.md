# UML Use Case Diagram (Диаграмма прецедентов использования)

Диаграмма прецедентов использования отображает роли пользователей системы государственных закупок и доступные им операции в соответствии с политиками безопасности (Policies & Gates).

## Актёры (Actors)
* **Исполнитель (Ijrochi):** Инициатор договора, отвечает за фиксацию условий и приемку фактически поступивших партий товаров.
* **Руководитель (Boshliq):** Контролирующий орган, принимает решения по штрафным санкциям и отслеживает все контракты организации.
* **Бухгалтер (Buxgalter):** Управляет сметными ассигнованиями (бюджетом), проводит платежи по этапам финансирования и аннулирует ошибочные проводки.

---

## Диаграмма прецедентов (Mermaid)

```mermaid
flowchart LR
    subgraph Actors["Пользователи системы"]
        Executor["Исполнитель<br/>(Ijrochi)"]
        Supervisor["Руководитель<br/>(Boshliq)"]
        Accountant["Бухгалтер<br/>(Buxgalter)"]
    end

    subgraph System["Система управления поставками и бухгалтерией"]
        subgraph ContractModule["Модуль договоров"]
            UC1["Создать проект договора<br/>(Draft)"]
            UC2["Активировать договор<br/>(Active)"]
            UC3["Просмотр своих договоров"]
            UC4["Просмотр всех договоров"]
        end

        subgraph DeliveryModule["Модуль поставок"]
            UC5["Зарегистрировать партию товара<br/>(Платный + Бонусный)"]
            UC6["Авто-завершение договора<br/>(Completed)"]
        end

        subgraph PenaltyModule["Модуль штрафов и неустоек"]
            UC7["Расчет пени на дату<br/>(0.5% в день, лимит 50%)"]
            UC8["Утвердить штраф<br/>(Approved с суммой)"]
            UC9["Отклонить штраф<br/>(Rejected)"]
        end

        subgraph AccountingModule["Модуль бухгалтерии"]
            UC10["Ведение сметы расходов<br/>(Лимиты по месяцам)"]
            UC11["Регистрация платежа<br/>(5 последовательных проверок)"]
            UC12["Аннулирование платежа<br/>(Void с указанием причины)"]
            UC13["Авто-перерасчет остатков<br/>(Смета и этапы)"]
        end
    end

    Executor --> UC1
    Executor --> UC2
    Executor --> UC3
    Executor --> UC5

    Supervisor --> UC4
    Supervisor --> UC7
    Supervisor --> UC8
    Supervisor --> UC9

    Accountant --> UC4
    Accountant --> UC10
    Accountant --> UC11
    Accountant --> UC12

    UC5 -.->|При полной поставке| UC6
    UC11 -.->|Контроль баланса| UC13
    UC12 -.->|Восстановление лимитов| UC13
```

## Матрица прав доступа

| Прецедент (Use Case) | Исполнитель (Ijrochi) | Руководитель (Boshliq) | Бухгалтер (Buxgalter) |
| :--- | :---: | :---: | :---: |
| Создание договора (Draft) | Да | Нет | Нет |
| Активация договора (Active) | Да (свои) | Нет | Нет |
| Просмотр договоров | Только свои | Все | Все |
| Приемка партии товаров | Да (свои) | Нет | Нет |
| Расчет и предпросмотр пени | Да (просмотр) | Да | Да |
| Утверждение / отклонение пени | Нет | Да | Нет |
| Добавление строк сметы (Бюджет) | Нет | Нет | Да |
| Проведение оплаты по этапу | Нет | Нет | Да |
| Аннулирование платежа (Void) | Нет | Нет | Да |
